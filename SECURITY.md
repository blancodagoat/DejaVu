# Security Policy

## Supported versions

Only the [latest release](https://github.com/blancodagoat/DejaVu/releases/latest) is supported. There is no auto-updater, so please update manually before reporting.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately by email to **blancoleodagoat@gmail.com**.

You can expect an acknowledgement within a few days. Since DejaVu runs entirely locally (no network access, no uploads, no telemetry), the interesting surface is file handling, the recorded video on disk, and Win32/COM interop.
