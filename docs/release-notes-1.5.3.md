# DejaVu 1.5.3

DejaVu is back on GitHub: https://github.com/blancodagoat/DejaVu. This release points the app
there again. Nothing else changed since 1.5.2.

- **Update check:** "Check for updates" and "Notify about new versions" ask GitHub again.
  1.5.1 and 1.5.2 ask the old address, which will be switched off later, so update to 1.5.3
  to keep hearing about new versions.
- **Downloads:** every release is on the GitHub releases page.
- **Reporting a problem:** still the DejaVu Discord (https://discord.gg/NHke2BwRA6), in #support.
